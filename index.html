INFORMAÇÕES

Perguntas
frequentes.

Saiba mais sobre a experiência demonstrativa do AUREA.

O AUREA é um hotel real?

Não. O AUREA é um projeto fictício criado para demonstrar o desenvolvimento de um site premium para o setor de hotelaria.

É possível realizar uma reserva?

Não. Os formulários são interativos apenas para demonstração. Não existe disponibilidade real, cobrança ou confirmação de hospedagem.

As fotografias são do hotel?

Não. As imagens são referências visuais independentes utilizadas para ilustrar o conceito do projeto.

Os dados preenchidos são armazenados?

Não. Os formulários funcionam localmente no navegador e não enviam nem armazenam os dados informados.
